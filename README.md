# Proyecto_Limpieza_Datos_Recien_Nacidos
Limpieza y armonización de bases de recién nacidos del INEC (Ecuador) y el INEGI (México) con R, más un dashboard en Power BI. Proyecto colaborativo entre estudiantes de la PUCE y la Universidad Veracruzana

# Limpieza de datos: recién nacidos en Ecuador y México

Proyecto de la materia de Limpieza de Datos, desarrollado por un equipo
de 6 estudiantes: 3 de la Pontificia Universidad Católica del Ecuador
(PUCE) y 3 de una universidad de México.

## Objetivo
Limpiar y armonizar bases de datos de recién nacidos de ambos países,
con variables comparables, para poder analizarlas en conjunto.

## Fuentes de datos originales
- INEC (Ecuador): [https://www.ecuadorencifras.gob.ec/nacidos-vivos-y-defunciones-fetales/]
- INEGI (México): [https://www.inegi.org.mx/programas/natalidad/#datos_abiertos]

## Contenido del repositorio
- `scripts/`: dos scripts de R con el proceso de limpieza
- `data/clean/`: bases ya limpias (Ecuador y México)
- `dashboard/`: dashboard en Power BI (PDF)

## Herramientas
R / RStudio (limpieza de datos) y Power BI (visualización).
